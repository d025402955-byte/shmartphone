# שמרטפון

מערכת ניטור תינוק טלפונית על מרכזיית טכנוליין, עם ניהול מנויים.

- **שיחה נכנסת** (מודול API): בודקת שהמספר שייך למנוי מורשה (טלפון ראשי או נוסף), שואלת לאיזה מספר לשלוח התראות (נשמר למנוי), ומפעילה `noiseMonitor`.
- **אירועי ניטור**: רעש או ניתוק → שיחת התראה דרך API הקמפיינים, עם מניעת כפילויות ומרווח בין התראות.
- **דף ניהול** (`/admin`, משתמש `admin`): חיפוש, מנוי חדש, עריכה, "שולם" (הארכת חודש/שנה), ניסיון, השבתה, מחיקה, טלפונים נוספים, פעילות, ייבוא מרישומון וייצוא CSV.

ללא תלות חיצונית: Python 3.11+ בלבד, SQLite.

## שלוחות בטכנוליין

כל אפשרות היא שלוחת API נפרדת, עם הכתובת `https://<השרת>/ivr/<ivr_token>/<מצב>`:

| מקש | מצב | מה עושה |
|---|---|---|
| — | `menu` | תפריט ראשי מלא (אם רוצים שלוחה אחת לכל התפריט) |
| 1 | `activate` | הפעלת ניטור, רק למספר מאומת. כתובת בלי מצב = `activate` |
| 2 | `listen` | שלוחת שמרטף: האזנה לחדר פעיל ממספר מאומת או טלפון מורשה |
| 3 | `info` | הסבר על השירות |
| 4 | `phones` | הוספה, שמיעה והסרה של טלפונים מורשים |
| 5 | `verify` | אימות מספר לקבלת התראות (שיחה עם קוד בן 4 ספרות, או חיוג מאותו מספר) |
| 6 | `account` | מצב מנוי, מספרים מאומתים, טלפונים, אימות חדש |
| 9 | `message` | הקלטת הודעה לשירות הלקוחות ושליחתה למייל (לא בשימוש: טכנוליין שולחים מייל בעצמם) |
| — | `history` | היסטוריית רעשים: אירועי היממה האחרונה, עם שמיעת ההקלטות |
| — | `reconnect` | אחרי שהשיחה מהחדר התנתקה: מהטלפון של ההורה מבקשים חיוג חוזר לטלפון שבחדר, שעונה אוטומטית והניטור מתחדש (מוצע גם בשלוחה 2 כשאין ניטור פעיל). דורש `reconnect_extension` |
| — | `pay` | הצטרפות / חידוש מנוי בתשלום (גם מוצע אוטומטית למי שהניסיון או המנוי שלו הסתיים, ובמקש 5 בניהול חשבון) |

## תשלומים

- התשלום בטלפון דרך מודול `creditCard` של טכנוליין, שסולק בנדרים פלוס. פרטי הכרטיס לא עוברים בשרת הזה.
- חודשי: הוראת קבע חודשית (`kevaMonthly`). שנתי: חיוב אחד.
- כל תשלום נשלח עם הקטגוריה `שמרטפון <מספר מנוי>`. כל 20 דקות השרת קורא את היסטוריית העסקאות בנדרים פלוס (קריאה בלבד) ומאריך את המנוי על כל חיוב חודשי חדש.
- מנוי ששולם דרך המערכת נחסם 5 ימים אחרי תאריך התוקף אם לא התקבל חיוב. מנויים שיובאו מרישומון לא נחסמים לפי תאריך.
- הפעלה: `python3 /opt/shmartphone-app/install.py payments` (מחירים, מספר מוסד ומפתח API של נדרים פלוס עם הרשאת קריאת היסטוריית עסקאות).

הגדרת מייל: `python3 /opt/shmartphone-app/install.py smtp`

## התקנה בשרת

```
git clone https://github.com/d025402955-byte/shmartphone /opt/shmartphone-app
python3 /opt/shmartphone-app/install.py
```

עדכון: `cd /opt/shmartphone-app && git pull && python3 install.py`
חזרה לגרסה הקודמת: `python3 /opt/shmartphone-app/install.py rollback`
סיסמת ניהול חדשה: `python3 /opt/shmartphone-app/install.py password`

ההגדרות נשמרות ב-`/etc/shmartphone/app.json` (לא במאגר). הנתונים ב-`/var/lib/shmartphone/app.db`.

## כללי הרשאה

- `פעיל` → מורשה (חינם תמיד מורשה). עם `enforce_active_expiry: true` גם מנוי פעיל נחסם אחרי תאריך התוקף.
- `תקופת ניסיון` → מורשה עד תאריך התוקף.
- `מושבת` / `מבוטל` → לא מורשה.
- מספר לא מוכר מקבל ניסיון אוטומטי של `auto_trial_days` ימים (0 = כבוי).
